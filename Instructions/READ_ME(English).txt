Welcome to use GreatCalculator!

Instructions:
      Usage:
            Enter an arithmetic expression, examples:
                  1+2^(19999 + 1)
                  (1+2)*(2+3)*(3+4)
            Symbol Explanation:
                  +Add -Subtract *Multiply /Divide ^Power %Mod &Bitwise AND |Bitwise OR !Bitwise XOR
                  Note: ^ stands for exponentiation, ! stands for bitwise XOR. "!" only means bitwise XOR in this calculator.
            Press Enter to finish input.
            Expression Syntax:
                  Most syntax is consistent with standard mathematical expressions.
                  Differences:
                  1. Negative sign is not supported. Do not write -(2+5), use -1*(2+5) instead.
                  2. Omitted multiplication signs are not supported. Do not write 5(2+3), use 5*(2+3) instead.
                  3. Power operations are calculated from left to right. For example, 2^3^4 is calculated as (2^3)^4.
                  4. Bitwise operations have the lowest priority with equal precedence, executed from left to right.
                  5. This is a high-precision integer calculator. Division only retains the integer part, e.g. 10/3=3.
                  6. Only round brackets are supported; square brackets and curly brackets are unavailable. Valid example: 1+(2+(3+4)).
                  We apologize for the inconvenience caused by the above limitations.
            Input Tips:
            1. It is recommended to type closing brackets right after opening brackets to avoid bracket mismatch or missing brackets.
            2. If the expression starts with an operator, the program will automatically fill in the last valid result as the first operand; an error will be reported if no valid result exists.
      Remarks:
      1. The program automatically ignores spaces, commas and underscores, and removes leading zeros.
      2. Calculation may take longer when processing extremely large numbers, please wait patiently.
      3. Do not use this calculator for ultra-large number operations to avoid unknown exceptions.
